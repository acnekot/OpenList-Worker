ContextMenu is the right-click menu on files, written from the solid-contextmenu styles in the build.

Container is `surface-200` with `radius-sm`, `shadow-menu` and a 200px minimum. Items pad 6px 12px; hover uses a `brand-tint` fill with `brand` ink in light and a `brand-menu` fill with white in dark. Disabled items are 50% opacity. Separators are 1px `border`.
