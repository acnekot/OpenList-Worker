Button is the primary and outline action control, written from the upload button CSS in the build.

Use one primary (`brand` fill, white semibold 14.4px label, `radius-md`) per view; the outline variant (1px `brand` border, `brand` ink) is for secondary actions such as New folder. Hover darkens to `brand-hover`; press scales to 0.95. The consumer supplies the label and click handler.
